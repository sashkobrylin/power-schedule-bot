# Бот графіків відключень — Копичинецька громада

Кожні ~10 хвилин перевіряє [poweron.toe.com.ua](https://poweron.toe.com.ua/) для черг **3.1** (Копичинці) і **6.1** (Гадинківці) та надсилає картинку в Telegram-групу:

- з'явився графік на нову дату (наприклад, на завтра) → картинка із заголовком **«Графік»**;
- графік на вже опубліковану дату змінився → картинка із заголовком **«Оновлений графік»**.

Порівнюються лише години повного вимкнення, тобто саме те, що видно на картинці.

## Файли

| Файл | Що робить |
|---|---|
| `config.py` | черги, адреси для пошуку на сайті, тексти заголовків |
| `scrape.py` | відкриває сайт у headless-браузері, шукає за адресою, зчитує графік |
| `render.py` | заповнює `template/light-info.svg` і робить PNG |
| `bot.py` | порівнює з `state.json`, генерує й надсилає картинки |
| `.github/workflows/check.yml` | автоматичний запуск у GitHub Actions |

## Налаштування (один раз)

### 1. Telegram-бот
1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → збережіть **токен**.
2. Додайте бота в групу. Напишіть у групі будь-яке повідомлення.
3. Дізнайтеся ID групи (число на кшталт `-1001234567890`):
   ```bash
   TELEGRAM_BOT_TOKEN=ваш_токен .venv/bin/python get_chat_id.py
   ```

### 2. GitHub
1. Створіть **публічний** репозиторій. У публічних репозиторіях GitHub Actions безкоштовні без ліміту. Для приватного безкоштовних хвилин на запуск кожні 10 хв не вистачить. Токени в коді не зберігаються, тож публічність безпечна.
2. Завантажте туди вміст цієї папки.
3. **Settings → Secrets and variables → Actions → New repository secret**, додайте:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — ID групи.
4. **Actions** → «Перевірка графіків» → **Run workflow**, щоб перевірити одразу.

Перший запуск надішле графік, який зараз є на сайті. Якщо цього не хочете, перед завантаженням виконайте `.venv/bin/python bot.py --init` і закомітьте створений `state.json`.

## Локальна перевірка

```bash
.venv/bin/python scrape.py          # що зараз на сайті
.venv/bin/python bot.py --dry-run   # згенерувати картинки в out/ без надсилання
```

## Якщо щось зламалося
- **Обленерго перенесло адресу в іншу чергу.** Бот зупиниться з помилкою, і GitHub надішле вам лист. Замініть адресу в `config.py`.
- **Змінився дизайн сайту.** Найімовірніше, доведеться поправити `scrape.py`.
- **Новий дизайн картинки.** Замініть `template/light-info.svg`, зберігши шари `title`, `date`, `hours1`, `hours2`. Якщо змінилися позиції або розміри тексту, поправте `TITLE` і `HOURS` у `render.py`.
